# Ээлж — Fuel Queue MN 2.0.0

WordPress theme-ээс тусдаа, гар утасны зориулалтын нэг нүүртэй шатахууны цахим оочир.
CSS, JavaScript, дүрсүүд ZIP дотроо багтсан. Гаднын CDN, font, npm, build команд шаардлагагүй.

## Суулгах — /test сервер

1. `/test` дээр WordPress суусан байх ёстой. Энэ ZIP нь бие даасан PHP сайт биш.
2. Үндсэн админ хэрэглэгчээр `http://172.16.7.36/test/wp-admin/` руу нэвтэр.
3. Өмнөх Fuel Queue MN идэвхтэй бол Deactivate хийнэ.
4. Plugins → Add New → Upload Plugin → `fuel-queue-mn.zip` → Install Now.
   Хуучин хувилбар байгаа тухай асуувал “Replace current with uploaded” сонгоно.
5. Activate дарна. Идэвхжүүлсэн админ нь плагиний цорын ганц үндсэн админ болно.
   FTP-ээр файл сольсон бол заавал Deactivate → Activate хийнэ.
6. Settings → General → Timezone хэсэгт `Asia/Ulaanbaatar` сонгоно.
7. Зүүн цэсийн “Шатахууны оочир” → “Ажилтан” → эхний эрхлэгчээ нэмнэ.
8. “ШТС” → салбаруудаа бүртгэж, хариуцах эрхлэгчийг онооно.
9. “Ажилтан” → түгээгч нэмээд нэг эрхлэгчийн хүрээнд ажиллах ШТС-уудыг сонгоно.
   Эрхлэгч өөрөө мөн нүүрээр нэвтэрч түгээгч бүртгэж болно.
10. “Гар утасны нүүрийг нээх” товчоор үйлчилгээ рүү орно.

### /test/ хаягийг шууд шинэ нүүр болгох

Settings → Reading → Your homepage displays → A static page → Homepage дээр
“Шатахууны оочир” (шинэ `fuel-queue-app` хуудас) сонгоод Save Changes дарна.
Одоо `http://172.16.7.36/test/` шууд бие даасан шинэ загвараар нээгдэнэ.
Plugin сайтын бусад хуудасны theme-ийг өөрчлөхгүй.

Админ дахь нүүр нээх товч `?page_id=...` холбоос ашигладаг тул Apache rewrite
тохиргоогүй /test дэд хавтас дээр ч нээгдэнэ.

Өмнөх 0.1 хувилбарын 4 хуудас байсан бол Pages хэсгээс хуучин
`fuel-queue`, `fuel-queue-book`, `fuel-queue-my`, `fuel-queue-station` хуудсуудыг
устгаж болно. Шинэ `fuel-queue-app` хуудсыг бүү устга.
Энэ хувилбар хуучин хуудсыг автоматаар устгахгүй.

## Шаардлага

- WordPress 5.8 ба түүнээс дээш; PHP 7.4 ба түүнээс дээш.
- MySQL/MariaDB, InnoDB хүснэгт, `GET_LOCK` / `RELEASE_LOCK` боломжтой байх.
- WordPress-ийн өгөгдлийн сангийн хэрэглэгч CREATE / ALTER / INDEX болон
  SELECT / INSERT / UPDATE / DELETE эрхтэй байх.
- Гар утасны орчин үеийн хөтөч, JavaScript болон cookie идэвхтэй байх.
- Интернэтэд олон нийтэд нээхдээ HTTPS, дэмжигдэж буй WordPress/PHP ашиглана.
  HTTP дотоод сүлжээний туршилтад ажиллана.
- 172.16.7.36 нь дотоод IP: гар утас тухайн Wi-Fi/LAN/VPN-д холбогдсон үед
  хандана. Гар утасны датагаар нийтэд ашиглуулахад нийтэд хүрэх хаяг шаардлагатай.

## Эрхийн бүтэц

- **Админ — нэг хэрэглэгч:** WordPress admin panel, бүх ШТС, эрхлэгч,
  түгээгч болон бүх салбарт мөрдөх давхар захиалгын дүрэм.
- **Эрхлэгч:** өөрт оноосон олон ШТС; оочир үүсгэх, тохиргоо засах,
  хуулж шинээр үүсгэх, түр зогсоох, нээх/хаах; түгээгч нэмэх, нууц үгийг
  шинэчлэх, ажиллах салбаруудыг нь сонгох; өөрийн салбаруудын захиалгын дүрэм.
- **Түгээгч:** нэг эрхлэгчийн хүрээнд хэд хэдэн ШТС-д ажиллах боломжтой.
  Нүүр дээр ажиллах салбараа сонгоод өнөөдрийн дарааллыг удирдана.
- **Жолооч:** хэрэглэгчийн бүртгэлгүй; машины дугаар, утсаар оочир авна.

Эрхлэгч, түгээгчид WordPress admin panel болон дээд хэрэгслийн мөр харагдахгүй.
/wp-admin/ руу шууд хандвал нүүр рүү буцна. AJAX хүсэлт бүрийн эрхийг сервер
талд шалгана. Өөр эрхлэгчийн ШТС-ын ID-г зориуд илгээсэн ч хандахгүй.

## Оочрын ажиллагаа

1. Эрхлэгч нүүрийн “Ажилтан нэвтрэх” хэсгээр орно.
2. Салбараа сонгоод “Шинэ оочир” дарна.
3. Үйлчлэх огноо, шатахуун, машины тоо, мөнгөн лимитээ оруулна.
4. Бүртгэлийн нээх/хаах цагийг хоосон орхивол шууд захиалга авч,
   үйлчлэх өдрийн төгсгөл хүртэл нээлттэй байна. Энэ цаг нь захиалга авах цаг;
   түгээгч үйлчилгээ үзүүлэхийг үйлчлэх огноо болон нээлттэй төлөв шийднэ.
5. “Хуулж үүсгэх” өмнөх тохиргоог дараагийн өдөрт санал болгоно. Хэрэв
   өмнөх оочир хуучирсан бол өнөөдрөөс дараагийн өдөр сонгоно. Нээх/хаах
   цагийн огноог мөн ижил өдрийн зөрүүгээр шилжүүлнэ. Хадгалахаасаа өмнө засаж болно.
6. Хуулсан оочирт хүмүүс хуулэгдэхгүй, №1-ээс шинээр эхэлнэ.
7. Хүн бүртгүүлсний дараа огноо, шатахуун, мөнгөн лимитийг өөрчлөхгүй.
   Машины тоог нэмэгдүүлж болно, бүртгүүлсэн тооноос бууруулахгүй.
8. Түр зогсооход шалтгаан шаардлагатай; жолоочид тайлбар харагдаж, захиалга
   болон үйлчилгээ түр зогсоно. Нээхэд өмнөх дараалал үргэлжилнэ.
9. Түгээгч дарааллын эхний машиныг “Үйлчилсэн” / “Ирээгүй” гэж тэмдэглэнэ.
   Өөрөө хийсэн үйлдлээ 30 секундэд “Буцаах” товчоор буцаана.
10. Цуцлагдсан эрх дахин захиалахад нээгдэнэ. Хуучин дугаарыг дахин олгохгүй:
    №3 цуцлагдвал дараагийн шинэ захиалга №4, №5 гэх мэт үргэлжилнэ.

## Давхар захиалгын дүрэм

- Нэг оочирт нэг машин давхар бүртгэгдэхгүй.
- Эрхлэгч “Миний эрх → Захиалгын дүрэм”-д өөрийн бүх салбар нийлээд
  нэг машин өдөрт нэг оочир, эсвэл ШТС бүрд нэг оочир гэсэн сонголттой.
- Админ хүсвэл бүх эрхлэгчийн ШТС-ыг хамруулан өдөрт нэг оочроор хязгаарлана.
- Өдрийг захиалга өгсөн өдрөөр бус **үйлчлэх огноогоор** тооцно.
- “Үйлчилсэн”, “Ирээгүй” захиалга өдрийн хязгаарт тооцогдоно; цуцалсан нь тооцогдохгүй.
- Дүрэм шинэ захиалгад үйлчилнэ. Өмнөх захиалгуудыг устгахгүй.
- Эрхлэгчийн дүрэм нь салбаруудад нийтлэг: нэг оочроос нөгөөг хуулсан ч
  тухайн эрхлэгчийн хүчинтэй дүрмийг ашиглана.

## Захиалгын нууц эрх, хувийн мэдээлэл

Утас 8 оронтой; улсын дугаар 4 тоо + 3 кирилл үсэг (жишээ 1234ЗАН).
Жижиг кирилл үсгийг том болгож, зай/зураасыг арилгана. Латин үсгийг
төөрөгдүүлэн автоматаар хөрвүүлэхгүй.

Захиалга авсан хөтөч HttpOnly, SameSite cookie-д нууц эрх хадгална.
“My оочир” зөвхөн тэр хөтчийн захиалгуудыг харуулж цуцлуулна.
Өгөгдлийн санд cookie-ийн эх утга бус HMAC хэш хадгална.
Утасны дугаарыг мэдсэнээр бусдын захиалгыг харах/цуцлах боломжгүй.

- SMS, OTP, push notification энэ хувилбарт **байхгүй**.
- Утасны эзэмшлийг баталгаажуулахгүй.
- Хөтчийн cookie-г устгах, өөр төхөөрөмж ашиглах, private mode-оос гарахад
  хуучин захиалгыг хэрэглэгч өөрөө сэргээх боломжгүй. Тухайн ШТС-тай холбогдоно.
- Жолоочийн дэлгэц 10 секунд тутам шинэчлэгдэнэ. Шинэчлэх үед сүлжээ хэрэгтэй.
- Түгээгч өөрийн ШТС-ын захиалгын бүтэн машины дугаар, утсыг харна.
- Гаднаас ирсэн IP header-д итгэхгүй, серверийн REMOTE_ADDR-аар оролдлого тоолно.
- Нэвтрэх: нэг IP-аас 5 минутад 12 оролдлого. Захиалах/цуцлах: тус бүр
  нэг IP-аас 5 минутад 30 оролдлого. Нэг Wi-Fi/NAT-аас маш олон хүн зэрэг
  ашиглах үед энэ хязгаарыг бодит ачаалалд тааруулж тохируулах шаардлагатай.

## Загвар

Theme-ээс хамаарахгүй бүрэн HTML дэлгэц; white/forest-green өнгө, 18px үндсэн
бичвэр, 58px үндсэн товч, том дарааллын тасалбар. Нэг баганатай картууд,
доод цэс, товчлуурын бичгэн тайлбар, focus хүрээ, маягтын шошго, өнгө+үгээр
төлөв ялгах, баталгаажуулах цонхны keyboard focus, алдааны мэдэгдэлтэй.
Жолооч, эрхлэгч, түгээгчийн үйлдлүүд нэг хуудасны дотор солигдоно.
Компьютероор нээвэл гар утасны өргөнтэй төвлөрсөн дэлгэц харагдана.

## Алдаа гарвал

- **Хоосон дэлгэц:** ZIP-ийг /test дотор шууд задлах биш WordPress Plugins хэсгээр суулгасан эсэх.
- **Нүүр хуучин theme-тэй:** Pages дахь шинэ “Шатахууны оочир” хуудас эсвэл админы
  “Гар утасны нүүрийг нээх” товчоор нээнэ. Homepage тохиргоогоо шалгана.
- **ШТС харагдахгүй:** эрхлэгч, идэвхтэй ШТС болон өнөөдөр/ирээдүйн оочир үүсгэсэн эсэх.
- **Оочир авч болохгүй:** нээх/хаах цаг, огноо, үлдсэн эрх, түр зогсолт, давхар захиалгын дүрэм.
- **Хүсэлтийн хугацаа дууссан:** хуудсаа шинэчил. Cache plugin/proxy ашиглавал энэ нүүр болон
  `wp-admin/admin-ajax.php`-г кэшээс хасна. Олон домэйн холихгүй; WordPress-ийн Site URL тохиргоог шалгана.
- **Сервер завгүй:** MySQL хэрэглэгч GET_LOCK ажиллуулах боломжтой эсэх, DB холболт болон ачаалал.
- **Шинэ самбар харагдахгүй:** хуучин плагинтай давхар идэвхжүүлээгүй эсэх; шинэ файлаа орлуулаад идэвхжүүл.
- **Гар утаснаас сайт нээгдэхгүй:** ижил LAN/Wi-Fi, Apache firewall болон IP/портын хандалт.

## Өгөгдөл

`fqm2_batches`, `fqm2_tickets`, `fqm2_audit`, `fqm2_rates` хүснэгт ашиглана.

захиалгын түүхийг автоматаар устгахгүй.
